## The word

**ROBUT** — grandma's typo for ROBOT.

One word, exactly what grandma would text about AI: warm, a little
baffled, funny on its own, tied to robots and machines, and a fresh
twist on the obvious pick.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the
single word `ROBUT` to `/output/entry.txt`. Nothing else.

```sh
python3 main.py   # writes /output/entry.txt containing: ROBUT
```
